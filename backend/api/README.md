# AI Multi-Disease Risk Screening Backend API

A modular, lightweight Flask REST API exposing risk screening prediction endpoints for chronic and critical conditions.

## Architecture & Design Principles
- **Separation of Concerns**: API routing and request validation (`backend/api/`) are decoupled from model execution (`backend/services/prediction_service.py`), which invokes existing disease model modules without duplicating preprocessing logic.
- **Stateless Inference**: Endpoints perform forward-pass model inference only. Models are never retrained or modified during API startup or request execution.
- **Consistent Schema Validation**: Strict input validation against formal contracts derived from `feature_schema.json`.
- **Safe Error Responses**: Uniform JSON error envelopes without exposing stack traces, filesystem paths, or internal implementation details.
- **Non-Diagnostic Scope**: All prediction outputs are strictly statistical risk-screening assessments and do not constitute clinical diagnoses.

## Endpoints

### 1. Health & Liveness Check
- **Endpoint**: `GET /api/health`
- **Description**: Lightweight health check endpoint. Does not require database or authentication.
- **Response `200 OK`**:
  ```json
  {
    "service": "ai-multi-disease-risk-screening-api",
    "status": "ok"
  }
  ```

---

### 2. Available Models Check
- **Endpoint**: `GET /api/models`
- **Description**: Verifies that serialized model artifacts (`model.joblib`, `preprocessor.joblib`, and inference modules) can be loaded, returning real-time availability.
- **Response `200 OK`**:
  ```json
  {
    "models": [
      {
        "available": true,
        "disease": "lung_cancer"
      },
      {
        "available": true,
        "disease": "asthma"
      },
      {
        "available": true,
        "disease": "parkinsons"
      }
    ]
  }
  ```

---

### 3. Lung Cancer Risk Screening
- **Endpoint**: `POST /api/predict/lung-cancer`
- **Content-Type**: `application/json`
- **Required Input Fields**:
  - `gender`: string (`"MALE"` or `"FEMALE"`)
  - `age`: numeric (1 to 120)
  - `smoking`: integer (1 or 2, or binary indicator)
  - `yellow_fingers`: integer
  - `anxiety`: integer
  - `peer_pressure`: integer
  - `chronic_disease`: integer
  - `fatigue`: integer
  - `allergy`: integer
  - `wheezing`: integer
  - `alcohol_consuming`: integer
  - `coughing`: integer
  - `shortness_of_breath`: integer
  - `swallowing_difficulty`: integer
  - `chest_pain`: integer
- **Example Request Payload**:
  ```json
  {
    "gender": "MALE",
    "age": 65,
    "smoking": 1,
    "yellow_fingers": 1,
    "anxiety": 1,
    "peer_pressure": 0,
    "chronic_disease": 1,
    "fatigue": 1,
    "allergy": 1,
    "wheezing": 1,
    "alcohol_consuming": 1,
    "coughing": 1,
    "shortness_of_breath": 1,
    "swallowing_difficulty": 0,
    "chest_pain": 1
  }
  ```
- **Example Response `200 OK`**:
  ```json
  {
    "disease": "lung_cancer",
    "prediction": {
      "class": 1,
      "disclaimer": "This prediction is generated by a statistical screening model and does NOT constitute a clinical diagnosis. Consult a pulmonologist for medical evaluation.",
      "prediction": "YES",
      "probability": 0.945,
      "risk_level": "High"
    }
  }
  ```

### 4. Asthma Risk Screening
- **Endpoint**: `POST /api/predict/asthma`
- **Content-Type**: `application/json`
- **Required Input Fields**:
  - `Age`: numeric (1.0 to 120.0)
  - `Gender`: string (`"Female"`, `"Male"`, or `"Other"`)
  - `BMI`: numeric (10.0 to 65.0)
  - `Smoking_Status`: string (`"Never"`, `"Former"`, `"Current"`)
  - `Family_History`: integer (`0` or `1`)
  - `Allergies`: string (`"None"`, `"Dust"`, `"Pollen"`, `"Pets"`, `"Multiple"`)
  - `Air_Pollution_Level`: string (`"Low"`, `"Moderate"`, `"High"`)
  - `Physical_Activity_Level`: string (`"Sedentary"`, `"Moderate"`, `"Active"`)
  - `Occupation_Type`: string (`"Indoor"`, `"Outdoor"`)
  - `Comorbidities`: string (`"None"`, `"Diabetes"`, `"Hypertension"`, `"Both"`)
  - `Medication_Adherence`: numeric (0.0 to 1.0)
  - `Number_of_ER_Visits`: numeric (0.0 to 20.0)
  - `Peak_Expiratory_Flow`: numeric (50.0 to 900.0)
  - `FeNO_Level`: numeric (0.0 to 150.0)
- **Example Request Payload**:
  ```json
  {
    "Age": 45,
    "Gender": "Female",
    "BMI": 28.5,
    "Smoking_Status": "Former",
    "Family_History": 1,
    "Allergies": "Pollen",
    "Air_Pollution_Level": "High",
    "Physical_Activity_Level": "Sedentary",
    "Occupation_Type": "Indoor",
    "Comorbidities": "None",
    "Medication_Adherence": 0.65,
    "Number_of_ER_Visits": 1,
    "Peak_Expiratory_Flow": 350.0,
    "FeNO_Level": 35.0
  }
  ```
- **Example Response `200 OK`**:
  ```json
  {
    "disease": "asthma",
    "prediction": {
      "class": 1,
      "disclaimer": "This model is an AI-based asthma risk-screening research component and is not a clinically validated diagnostic system. Consult a qualified pulmonologist for diagnosis.",
      "prediction": "Has Asthma",
      "probability": 1.0,
      "risk_level": "High",
      "risk_tier_basis": "Software-defined heuristic category (<0.30 Low, 0.30-0.70 Moderate, >=0.70 High), not a clinical threshold."
    }
  }
  ```

## Error Handling

All errors return a consistent, safe JSON structure without leaking internal execution details:

```json
{
  "error": {
    "code": "INVALID_INPUT",
    "message": "Missing required feature(s): ['Age']"
  }
}
```

| HTTP Status | Error Code | Scenario |
| :--- | :--- | :--- |
| `400 Bad Request` | `INVALID_REQUEST` | Request content-type is not `application/json` |
| `400 Bad Request` | `INVALID_INPUT` | Missing required features, invalid data types, or out-of-bounds values |
| `404 Not Found` | `NOT_FOUND` | Unknown route or resource requested |
| `405 Method Not Allowed` | `METHOD_NOT_ALLOWED` | Disallowed HTTP verb on route |
| `500 Server Error` | `MODEL_UNAVAILABLE` | Model artifacts missing or unreadable |
| `500 Server Error` | `INTERNAL_SERVER_ERROR` | Unexpected server execution error |
